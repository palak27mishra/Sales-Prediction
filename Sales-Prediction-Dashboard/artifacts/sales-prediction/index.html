05 / ABOUT THIS PROJECT

Analytics, with
the receipts.

SalesPredict AI is an interactive workspace for understanding a classic advertising dataset. It makes the source data explorable while being explicit about what the existing Python notebook can—and cannot—do.

Source file: 200 observations with TV, radio, newspaper and sales columns. The CSV is bundled with this frontend and parsed in the browser.
